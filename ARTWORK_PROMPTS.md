# Original 2D card artwork

Generated with the built-in image generation tool for TCG Unboxing Sim. The eight transparent 5×5 sheets contain 200 base illustrations: 50 per collection. In-game frames and four collectible editions create 800 cards. Only the final flat cartoon sheets listed below are used in this build. User references were supplied as illustration-style references; original subjects were requested.

Mix humanoid creature avatar busts and full-bodied monsters.
